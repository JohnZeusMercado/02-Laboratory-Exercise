# 02-Laboratory-Exercise
The product catalog app use a flutter application that displays five category products with their images, name, prices, categories, and description. Users can tap a product to view the details of the products. The application also has supports light mode and dark mode theme whether of the user preference for their comfort on their eyes. the main feature that been used the five sample product, shows the product images and prices, allows the user to view the detail of the product, has a supports light and dark theme for user preference theme, and has adjusts layout based on screen size. The screenshots folder contains the example of the mobile list, tablet grid, desktop grid, product details, and dark mode.
